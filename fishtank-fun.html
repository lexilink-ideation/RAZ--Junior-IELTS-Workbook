🧩 Sentence Patterns

My fishtank has a ___.
I can pretend I'm a/an ___.
Living alone in a ___ can be boring.

📐 Key Grammar

Present tense "has": My fishtank has a treasure chest.
"a" vs "an": use "a" before consonant sounds, "an" before vowel sounds — I can pretend I'm a pirate! / I can pretend I'm an alien.
Exclamation marks (!) show excitement: I can pretend I'm a knight!
