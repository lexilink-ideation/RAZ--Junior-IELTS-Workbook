第一本：《How Many Legs?》（有几条腿？）
Lexile BR40L  字数 41 words

阅读主题：
本书介绍了不同动物拥有不同数量的腿，从两条腿到多到数不清。学生通过观察各种动物的照片，学习数字与动物知识。

词汇（共10个）：
animal     动物    名词
legs       腿      名词
many       许多    形容词
two        二      形容词
four       四      形容词
six        六      形容词
eight      八      形容词
ten        十      形容词
have       有      动词
count      数数    动词

短语：
have legs            有腿
how many             多少
many animals         许多动物
these animals        这些动物
too many to count    多到数不清

语法重点：
• 一般现在时（Simple Present）：描述动物的固定特征 — 书中例句：These animals have four legs.
• 复数名词（Plural Nouns）：animal → animals，leg → legs — 书中例句：Many animals have legs.
• 数词作定语（Numbers as Adjectives）：直接修饰名词 — 书中例句：These animals have eight legs.

重点句：
These animals have eight legs.
这些动物有八条腿。
句子结构：
These animals（主语 — 这些动物）/ have（谓语动词 — 有）/ eight legs（宾语 — 八条腿）

Many animals have legs.
许多动物有腿。
句子结构：
Many animals（主语 — 许多动物，many修饰animal的复数形式）/ have（谓语）/ legs（宾语 — 腿）

例句：
1. Many animals have legs.
2. These animals have two legs.
3. These animals have four legs.
4. These animals have eight legs.
5. How many legs do these animals have?


第二本：《So Many Shops》（这么多商店）
Lexile 40L  字数 35 words

阅读主题：
本书带领小读者参观各种不同的商店，每家店出售不同的食物——面包、鱼、花、肉、奶酪、水果和蔬菜。学生在阅读中了解商店的种类，感受购物的乐趣。

词汇（共10个）：
shop         商店    名词
sell         出售    动词
bread        面包    名词
fish         鱼      名词
flowers      花      名词
meat         肉      名词
cheese       奶酪    名词
fruit        水果    名词
vegetables   蔬菜    名词
many         许多    形容词

短语：
this shop sells       这家店出售
so many shops         这么多商店
so many things        这么多东西
sell bread / fish / flowers / meat / cheese / fruit / vegetables
出售面包 / 鱼 / 花 / 肉 / 奶酪 / 水果 / 蔬菜

语法重点：
• 一般现在时（Simple Present）：描述商店日常出售的商品 — 书中例句：This shop sells bread.
• 指示代词（Demonstrative Pronoun）："This" 指代眼前这家商店 — 书中例句：This shop sells fish.
• 复数名词（Plural Nouns）：shop → shops，flower → flowers，vegetable → vegetables — 书中例句：So many shops sell so many things!

重点句：
This shop sells bread.
这家商店出售面包。
句子结构：
This shop（主语 — 这家商店，this表示特指）/ sells（谓语 — 第三人称单数sell加s）/ bread（宾语 — 面包）

So many shops sell so many things!
这么多商店出售这么多东西！
句子结构：
So many shops（主语 — 这么多商店，so many表示"非常多"）/ sell（谓语）/ so many things（宾语）

例句：
1. This shop sells bread.
2. This shop sells fish.
3. This shop sells flowers.
4. This shop sells vegetables.
5. So many shops sell so many things!

今天共完成了两本 RAZ Level B 读物的阅读学习。
本节课主要学习了：

《How Many Legs?》
• 核心词汇：animal, legs, many, two, four, six, eight, ten, have, count
• 常用表达：have legs, how many, many animals, these animals, too many to count
• 语法重点：一般现在时陈述事实；复数名词；数词修饰名词
• 阅读主题：不同动物有不同数量的腿，从两条（鸟类）到数不清（蜈蚣）

《So Many Shops》
• 核心词汇：shop, sell, bread, fish, flowers, meat, cheese, fruit, vegetables, many
• 常用表达：this shop sells, so many shops, so many things
• 语法重点：一般现在时描述商店功能；this的指示用法；名词复数形式
• 阅读主题：不同的商店出售不同的食物和商品，购物很有趣！

两本书共同语法亮点：
两本书都练习了一般现在时和复数名词，同时 many 一词在两本书中都有出现，是很好的跨书复习机会。

课堂表现：

课后建议：
1. 复习两本书的词汇，重点掌握：animal, legs, have, shop, sell, vegetables, fruit；
2. 大声朗读两本书，注意句型节奏：
   "These animals have ___ legs."
   "This shop sells ___."
3. 完成两本书的互动练习册；
4. 尝试连接两本书的内容造句：What animals do you see in the shop? / How many legs does a fish have?
