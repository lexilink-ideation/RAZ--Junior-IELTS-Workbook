7月7日阅读笔记
📖 RAZ 分级读物 Level B ·《The Big Game》
Lexile 90L  字数 46 words

阅读主题：
本书讲述了一家人在比赛日当天的日常活动，从打扫房间、精心打扮，到与朋友相聚、画脸彩绘、吃零食、看比赛和为球队欢呼加油，展现了家庭传统与团队精神。

词汇（共9个）：
game 比赛 n.
clean 打扫 v.
dress up 打扮 v.
friends 朋友 n.
paint 涂色 v.
snacks 零食 n.
watch 观看 v.
cheer 欢呼 v.
football 橄榄球 n.

短语：
on game day 在比赛日那天
dress up 打扮
paint faces 画脸彩绘
eat snacks 吃零食
play football 打橄榄球

语法重点：
• 一般现在时描述习惯性动作（Simple Present for habits）— 书中例句：We clean on game day.
• 动词+宾语结构（Verb + Object）— 书中例句：We paint faces on game day.
• 时间状语"on game day"表示动作发生的时间 — 书中例句：We cheer on game day.

重点句：
We paint faces on game day.
我们在比赛日那天画脸彩绘。
句子结构：
主语(We) / 谓语动词(paint) / 宾语(faces) / 时间状语(on game day)

We play football on game day!
我们在比赛日那天打橄榄球！
句子结构：
主语(We) / 谓语动词(play) / 宾语(football) / 时间状语(on game day)，感叹句表达兴奋情绪

例句：
1. We clean on game day.
2. We see friends on game day.
3. We eat snacks on game day.
4. We watch football on game day.
5. We cheer on game day.
