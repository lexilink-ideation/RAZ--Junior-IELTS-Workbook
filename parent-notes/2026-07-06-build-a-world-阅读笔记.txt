7月6日阅读笔记
📖 RAZ 分级读物 Level C ·《Build a World》
Lexile 110L  字数 62 words

阅读主题：
这本书讲述了一个孩子用平板电脑上的绘画软件，一点一点地创造出一个属于自己的世界。孩子先从空白的画面开始，依次加入太阳、小山、河流、树木、云朵、鲜花和朋友，最终把世界变得丰富多彩。

词汇（共9个）：
build 建造 动词
world 世界 名词
empty 空的 形容词
full 满的 形容词
add 添加 动词
hills 小山 名词
clouds 云 名词
flowers 花 名词
friends 朋友 名词

短语：
add...to my world 把……添加到我的世界里
build a world 建造一个世界
when I start 当我开始的时候
that is full 是满的（定语从句修饰world）
I like it here 我喜欢这里

语法重点：
• be动词 + 形容词表状态 — 书中例句：My world is empty when I start.
• will + 动词原形表将来时 — 书中例句：I will build a world that is full.
• 一般现在时描述重复动作 — 书中例句：I add a sun to my world.

重点句：
My world is empty when I start. I will build a world that is full.
我的世界一开始是空的。我要建造一个满满的世界。
句子结构：
My world（主语）+ is empty（系动词+表语，描述状态）+ when I start（时间状语从句，说明"什么时候"是空的）。第二句 I（主语）+ will build（将来时谓语）+ a world（宾语）+ that is full（定语从句，修饰"world"，说明世界的样子）。

例句：
1. My world is empty when I start.
2. I will build a world that is full.
3. I add a sun to my world.
4. I add hills to my world.
5. I add friends to my world. We like it here!
