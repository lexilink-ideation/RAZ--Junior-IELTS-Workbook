6月20日阅读笔记
📖 RAZ 分级读物 Level B ·《So Many Shops》（这么多商店）
Lexile 40L  字数 35 words

阅读主题：
本书带领小读者参观各种不同的商店，每家店出售不同的食物——面包、鱼、花、肉、奶酪、水果和蔬菜。学生在阅读中了解商店的种类，感受购物的乐趣。

词汇（共10个）：
shop 商店 名词
sell 卖/出售 动词
bread 面包 名词
fish 鱼 名词
flowers 花 名词
meat 肉 名词
cheese 奶酪 名词
fruit 水果 名词
vegetables 蔬菜 名词
many 许多 形容词

短语：
this shop sells 这家店出售
so many shops 这么多商店
so many things 这么多东西
sell bread / fish / flowers / meat / cheese / fruit / vegetables 出售面包/鱼/花/肉/奶酪/水果/蔬菜

语法重点：
• 一般现在时（Simple Present）：描述商店日常出售的商品 — 书中例句：This shop sells bread.
• 指示代词（Demonstrative Pronoun）："This" 指代眼前这家商店 — 书中例句：This shop sells fish.
• 复数名词（Plural Nouns）：shop → shops，flower → flowers，vegetable → vegetables — 书中例句：So many shops sell so many things!

重点句：
This shop sells bread.
这家商店出售面包。
句子结构：
This shop（主语 — 这家商店，this表示特指）/ sells（谓语 — 出售，第三人称单数sell加s）/ bread（宾语 — 面包）

So many shops sell so many things!
这么多商店出售这么多东西！
句子结构：
So many shops（主语 — 这么多商店，so many表示"非常多"）/ sell（谓语）/ so many things（宾语）

例句：
1. This shop sells bread.
2. This shop sells fish.
3. This shop sells flowers.
4. This shop sells vegetables.
5. So many shops sell so many things!
